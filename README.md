# P0 — Aplicação com LLM

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma aplicação em Python que utiliza um Large Language Model (LLM) por meio de sua interface programática para solucionar um problema textual pequeno e real.

A proposta é desenvolver uma aplicação funcional e reproduzível, passando pelas etapas de identificação de uma necessidade, implementação, integração com um modelo de linguagem, testes e documentação.

## Objetivos

- Identificar e delimitar um problema textual real.
- Desenvolver uma aplicação utilizando Python.
- Integrar um modelo de linguagem por meio de sua interface programática.
- Implementar tratamento de erros e boas práticas de organização.
- Garantir que outra pessoa consiga compreender e executar o projeto.

## Desenvolvimento

O projeto será desenvolvido incrementalmente em três níveis:

- **Básico:** implementação do núcleo funcional da aplicação.
- **Intermediário:** melhoria da organização do código e do tratamento de erros.
- **Avançado:** conclusão da aplicação e preparação para execução reproduzível.

## Tecnologias

- Python
- Large Language Model (LLM) — a definir.
